# Introducing JonarchyMod: Keep Jonarchy at the Top of Your Server List

Minecraft has always been about freedom—the freedom to explore, build, and play on the servers you choose. That's why we created **JonarchyMod**, a lightweight Fabric client mod designed to make sure **jonarchy** is always at the top of your multiplayer server list, so you never have to hunt for it again.

JonarchyMod is simple, client-side, and focused on one goal: making sure jonarchy is always one click away.

## Why We Built It

Scrolling through a long multiplayer server list is annoying. Servers get buried under new additions, and too often players end up joining somewhere else simply because jonarchy wasn't easy to find.

JonarchyMod ensures that, whenever you open your multiplayer menu, jonarchy is there waiting at the top, ready to join.

## Features

- **Automatically adds jonarchy** to the top of your multiplayer server list if it isn't already present.
- **Reorders your list** so jonarchy always stays on top, even after other servers are added.
- **Client-side only** — no server installation required.
- **Supports multiple Fabric Minecraft versions.**
- **Lightweight and open source.**

## Privacy First

Unlike some other community mods that collect analytics or other usage information, **JonarchyMod collects absolutely no data**.

- No analytics
- No telemetry
- No tracking
- No accounts
- No background connections

Everything runs locally on your computer.

## Open Source

We believe players should be able to verify exactly what software they're running. That's why JonarchyMod is completely open source, allowing anyone to inspect the code, contribute improvements, or build it themselves.

## Installation

1. Install the Fabric Loader for your Minecraft version.
2. Download the latest JonarchyMod release.
3. Place the mod into your Minecraft `mods` folder.
4. Launch Minecraft using Fabric.
5. Join **jonarchy** as usual — it will be waiting at the top of your server list.

## Frequently Asked Questions

### Does this modify the server?

No. JonarchyMod is entirely client-side. Server owners do not need to install anything.

### Does it affect gameplay?

No. The mod only adds jonarchy to your multiplayer server list and keeps it at the top.

### Is any data sent anywhere?

No. JonarchyMod performs no analytics, telemetry, or data collection.

### Is it safe?

Because the project is open source, anyone can review exactly how it works before installing it.

## Looking Ahead

Our goal has always been to keep jonarchy accessible to everyone. JonarchyMod is another step toward making sure players can always find the server easily, no matter how crowded their server list gets.

Whether you're a longtime veteran or joining for the first time, JonarchyMod helps make sure the path to **jonarchy** stays open — and stays on top.
